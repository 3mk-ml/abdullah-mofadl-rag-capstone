## Minimum test script

Ask each person to:

1. Sign in with the demo password.
2. Choose one question from the built-in validated question list and run it.
3. Ask one custom agriculture question.
4. Open the five displayed evidence passages.
5. Check whether the answer cites evidence clearly.
6. Report whether the interface is easy to understand, whether the response time is acceptable, and what should be improved.

Record only feedback actually provided by the testers.
